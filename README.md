# Домашнее задание к занятию "Базы данных, их типы" - Князев Евгений

## Задание 1 
1.1 Реляционная база данных, можно использовать PostgreSQL

1.2 Можно использовать как SQL, так и NoSQL БД. Как пример MySQL и MongoDB

1.3 В данном случае можно использовать SQL базу данных, у нее будет более понятная структура. Как пример SQLite, MariaDB, PostgreSQL

1.4 Для быстрого решения такого рода задач, оптимально будет использовать графовый тип СУБД. Например Redis

## Задание 2
1. Инициализация запроса
2. Проверка доступности средств
3. Резервирование средств
4. Запрос на списание средств
5. Обновление баланса телефона

## Задание 3
1. Гарантированная целостность данных
2. Стандартизированный язык запросов
3. Эффективная работа со сложными связанными данными
4. Зрелая экосистема и широкая поддержка сообщества
5. Развитая система управления правами доступа

## Задание 4
Основными критериями при выборе будут: масштабируемость, производительность, отказоустойчивость, гибкость
Исходя из исходных данных, для распределенных вычислений можно использовать платформы Apache Hadoop или Apache Spark в сочетании с распределёнными СУБД, такими как Cassandra или HDFS.
